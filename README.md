# 演示工坊 · Anna Slide Workshop

演示工坊是 Anna 工作台里的演示文稿应用。输入主题或粘贴素材，规划 5–30 页简体中文或英文演示。依次确认大纲和逐页文字，选择模板，在 16:9 画布上修改内容，最后下载可编辑的 PPTX。首次打开可直接体验内置示例。

## 从素材到演示

1. 在演示需求里填写主题。按需补充受众、场景、目标、素材和必讲项。
2. 手工分配章节和页数，或请 Anna 起草大纲。逐页确认标题和这一页要讲清的内容。
3. 编辑投影正文、讲者备注和来源。Anna 按章节分批起草，生成中断后可继续未完成的页。
4. 在经营简报、编辑提案、课堂讲义和极简叙事中选择模板。每页可使用与位置兼容的版式，数据图表需填写数值、单位和来源。
5. 在排版里直接修改当前页，或请 Anna 起草单页候选。采纳前可以对照原稿。淡入淡出仅用于网页放映预览。
6. 检查缺页、必讲项、数据依据和文字溢出。结构问题修复后才可下载。可主动调用 Anna 检查素材依据和内容偏离，审阅建议后再导出。

PPTX 包含原生文字框、形状、数据图表及讲者备注。PowerPoint 可以继续编辑这些对象。图表的坐标轴和文字换行由办公软件排版。

## 草稿和 Anna 额度

连接宿主后，草稿保存在当前账号的 App 专属 Anna APS 空间。顶部显示宿主确认的保存状态。页面顺序、当前步骤、模板、模型偏好和已完成批次随草稿恢复。返工时按页标记待更新，原稿可供复核。

离开 Anna 时可用「草稿副本」下载 JSON，新开窗口后用「导入草稿文件」继续。共享设备上请自行管理已下载的文件。Anna 保存失败或冲突时也可用这份副本保留窗口中的编辑。

应用在连接后读取 Anna 文本模型目录。模型选择是路由偏好。目录暂不可用时可填写经平台核对的完整模型 ID。每次付费操作显示处理范围和预计调用次数，回执显示请求偏好、实际模型、推理档和 CU。手工编辑、翻页、换模板、恢复草稿和导出无需模型额度。

## 开发和验收

构建需要 Node.js 22 或更新版本。Anna harness 还需要 uv 提供的 uvx。

```sh
npm ci
npm test
npm run build
npm run validate
```

通过静态服务器打开构建好的 bundle/ 可体验示例、手工编辑和文件草稿。连接 staging 的官方 harness 时，先完成设备授权，再用 APS 模式运行。

```sh
npx anna-app login --host https://staging.anna.partners --no-browser
npx anna-app dev --slug slide-workshop --llm-account https://staging.anna.partners --storage aps
```

manifest 使用 schema 4。默认 App 自有存储无需跨应用存储声明。当前适配 APS 的 ETag 回执，初始化时宿主要求省略 ETag，后续写入附带上一版本的 ETag。大草稿先写分片，再更新索引。Anna 旧版内存存储模式下可使用文件草稿。

测试覆盖页数与 ID、批次恢复、模型路由回执、保存冲突和导出 XML。浏览器验收覆盖 1120×740、380×420 及 30 页恢复。PowerPoint 抽查已生成的文件，包含中文、英文长句、原生数据图表与末页。
