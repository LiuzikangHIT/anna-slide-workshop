# Anna 演示工坊开发计划

## 需求与范围

让需要快速准备汇报、培训或提案的 Anna 用户，把主题、受众和素材整理成投影片初稿。应用提供 5、7、9 页选项、逐页预览与编辑，并导出含原生文本及形状的 16:9 PPTX。面向 Anna 桌面工作台，中文界面支持生成中英文内容。

## 实现与验收

1. 创建 schema 4 的纯 UI Anna App。每次生成调用一次 `anna.llm.complete`，校验结构及长度，展示明确的失败反馈。用离线测试验证生成请求、异常处理和页面数量。
2. 将结构化内容投影到同一套预览和 PPTX 布局。校验导出文件的 ZIP 结构、页数、可编辑元素和 XML 转义。
3. 构建并用平台 CLI 校验清单。在 Anna staging 安装或预览并进行一次真实生成，检查 CU 消耗、逐页编辑和实际下载。
4. 将源代码交付到可供评审访问的 GitHub 仓库，上传 staging 版本并提交审核。审核通过后发布，验证其他用户可安装。

## 额度策略

离线覆盖成功、失败和导出，线上验证使用 5 页短素材。用户点击生成时请求平台模型，编辑、换主题和下载均在浏览器执行。记录平台返回的实际 CU。

## 结论

核心功能已实现。5 项离线测试与 Anna CLI 严格校验通过，覆盖单次模型请求、结构校验、截断处理、可编辑 PPTX 结构与浏览器导出。官方本地 harness 也完成了 main 窗口握手、模拟生成和五页 PPTX 导出验证，确认第二页修改出现在文件中，此次消耗 0 CU。GitHub 已公开。staging 的真实生成与审核状态见下方。
