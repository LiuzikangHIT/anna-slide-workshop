# 演示工坊 staging 扩展实测计划

## 需求与范围

应用户要求扩大 Anna staging 的真实模型验证，重点覆盖高密度业务材料、英文稿、有边界的培训内容和缺少证据的场景。沿用当前送审版本的应用逻辑。staging 版本若仍在审核，由官方 harness 接入同一 staging App 的模型服务。

## 执行与验收

1. 确认 staging 审核版本和本地工作区，核对真实模型宿主连接的应用。此次使用虚构测试素材。
2. 执行六个独立的生成请求，覆盖 5、7、9 页、中英文、数字约束、决策边界与素材内的无关指令。逐案记录模型、延迟、CU、是否生成成功及关键事实。异常记录后再判断是否有必要重试。
3. 每次成功生成后构造实际 PPTX，验证页数、16:9、原生文本、文本从生成结果传递到文件，以及一次本地编辑是否反映在文件中。样例保存在本地忽略目录。
4. 人工核对生成内容和素材，记录模型对数据、单位、决策对象及限制条件的处理。汇总累计 CU、发现的问题和平台公开安装状态。

## 结论

六份 PPTX 的结构及导出核验全部通过，共 46 页。每份都确认了实际页数、16:9 画幅、每页的原生文本与形状、封面标题，以及最后一页的本地改稿。实际文件与逐次用量报告位于本地 `.anna/staging-extended/`。
